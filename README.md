# Integrative analysis of HLA variation and single-cell regulatory associations in type 1 diabetes


## Overview

This repository contains scripts for analyzing HLA genetic associations, clinical phenotype associations, and single-cell eQTL analyses in type 1 diabetes.


## Workflow

1. HLA allele association analysis
2. HLA haplotype analysis
3. Phenome-wide association analysis
4. Single-cell eQTL analysis
5. HLA risk cell-type enrichment analysis


## Requirements

R >= 4.1
Python >= 3.10


## Data availability

Individual-level genotype and transcriptomic data are not publicly available due to privacy restrictions.
